## 28-1. Test Standards and CI Check

- **Codex**: 테스트 위치와 분리 조건, 줄 수 근거, 예외, 이동 전후 확인 방법을 [테스트 구성 기준](../TESTING.md)에 정리. ESLint 파일 상한과 기존 초과 파일 10개의 증량 방지, CI 연결 및 경계 테스트 추가. 기존 제품 테스트와 worker 설정 보존.
- **Claude review**: native `/code-review high`에서 기존 및 새 변경 파일 7개를 읽고 지적 10개 제시. 원문에서 지적별 등급은 미제공. 검토 도구 범위로 인해 직접 Git diff는 확인하지 못했으며, 검토 시점 파일과 변경 목록의 해시는 Codex가 고정 및 대조.
- **Codex response to review**: helper의 검사 경로를 보강하고 예외 전부를 실제 파일 길이와 대조. 지원 코드 자체의 테스트에 적용되는 상한을 문서화하고, CI에서 검사 자체의 실패를 테스트 환경 준비 전에 확인하도록 변경. 외부 제공자 계약의 현재 상한은 승인 범위를 유지하고 이동 시 기존 경로 규칙을 정리하도록 설명 추가.
- **Claude re-review**: 첫 두 차례에서 최종 기록 문안 확인 누락으로 검토 미완료. 두 번째 실행은 검토 전용 범위를 벗어나 테스트 실행. 세 번째 native `/code-review high`에서 변경 파일 7개, 후속 diff, 지적 처리 및 최종 문안 확인. 동작 회귀 없이 P3 6건 제시. 후속 대상 재검토에서 P3 6건의 처리, 관련 변경 및 최종 문안 확인.

### Pre-split Baseline

- 로컬: Windows, Node 22.23.2, pnpm 11.20.0, Vitest 5.0.1, Playwright 1.63.0, Chromium 153.0.8010.12, PostgreSQL 17.11. 통합과 브라우저는 로컬 테스트 DB에서 실행하며 브라우저 실행 전에 migration 적용.
- 로컬 개별 목록: 통합 외 Vitest 179건, PostgreSQL 통합 148건, Playwright 84건 확인. Vitest는 실제 등록 목록을 수집. 파일 병렬 실행 상한은 1이며 통합 외 실행에서 파일별 worker 25개 생성이 보고됨.
- 이전 CI: Ubuntu 24.04, Node 22.13.0, pnpm 11.20.0, Chromium 153.0.8010.12, PostgreSQL 17.12. 기존 179건, 148건과 Playwright 84건 모두 통과. Vitest 4.63초와 113.99초, Playwright worker 2개와 약 1분 확인. [PR #32 CI](https://github.com/sysysysyb/AMUQ/actions/runs/45162615172/job/137651543124)
- 이전 CI는 결과 건수와 시간의 근거로 사용. 28-1의 CI 출력에 개별 케이스 이름을 남겨 테스트 파일을 나누기 전 기본 실행 목록을 확보. 게시 뒤 검증 대기.

### Verification

- Red/Green: 401줄 파일 탐지, 통합 500줄 허용, 공백을 포함한 지원 파일 초과 탐지, 기존 예외 범위와 증량 금지, 인라인 주석 우회 차단의 의도한 실패 확인 후 5개 테스트 통과.
- 검토 후 회귀: 테스트 전용 디렉터리의 helper 누락과 실제보다 큰 예외 상한을 각각 재현. 수정과 예외 상한 복원 후 검사 5개 통과. 저장소 하위 폴더에서 같은 5개 통과.
- 재검토 후 회귀: 기본 상한 이내인 예외와 이동한 제공자 경로가 남았을 때 의도한 실패를 확인. 올바른 설정으로 복원한 뒤 새 경계 테스트를 포함한 CI 도구 테스트 46개 통과.
- 마지막 경로 회귀: 제품의 `app/test/` 경로에 상한이 걸리고 대괄호 파일 경로의 예외가 누락되는 현상을 재현. 두 경로를 수정하고 대괄호 경로의 예외가 인접 파일에 적용되지 않음을 확인.
- 로컬 제품 검증: 통합 외 Vitest 179개(12.03초), 실제 PostgreSQL 통합 148개(164.15초) 통과. Playwright 기본(worker 8개, 55.8초)과 단일 worker(약 66초) 모두 84개 통과.
- 로컬 첫 Playwright 실행은 테스트 84개 실행 뒤 웹 서버 종료가 멈춤. 해당 프로세스만 정리한 뒤 로컬 테스트 DB에서 두 실행을 다시 완료. 테스트와 runner 설정 변경 없이 종료 성공 확인.
- CI 도구: 대괄호 경로 테스트가 기본 400줄을 적용받아 실패하는 것을 확인한 뒤 47개 통과. 포맷, 린트, 타입 검사, 빌드 통과. 제품 UI 변경 범위가 없어 별도 시각 검사 미실행.
- CI 출력 재검증: Vitest의 두 reporter로 통합 외 179개와 실제 PostgreSQL 통합 148개 통과. 개별 케이스 이름 출력 및 테스트 DB 마이그레이션 복원 확인.
