## 결과와 범위

- 독립 Claude 리뷰, 정확한 변경의 커밋 승인, 로컬 자료 보존 규칙 정리
- GitHub Issue와 PR은 영어로 유지하고, 한국어 구현과 리뷰 기록은 Issue 목차와 PR별 문서로 정리했음. PR1에는 이 기록만 포함하고 후속 기록은 각 PR에서 추가 예정
- 코드, 테스트, DB, 실행 설정은 이번 문서 작업에서 변경하지 않음
- PR1에는 아래 기존 변경과 이번 추적 보고서 정리를 배정했음
  - **Git과 편집기 설정:** `.gitattributes`의 줄바꿈 규칙, `.vscode/settings.json`의 프로젝트 편집 설정과 `.gitignore`의 로컬 자료 제외 규칙
  - **에이전트 규칙:** `AGENTS.md`, `apps/web/AGENTS.md`의 구현, 독립 검토, 승인과 문서 작성 규칙
  - **로컬 자료의 Git 추적 해제:** `docs/planning/`의 기존 문서 3개와 `tools/figma-pretendard-refresh/`의 도구 파일 3개. 파일은 디스크에 보존하고 Git에서만 제외하도록 배정했음
    - **문서:** `project-handoff.md`, `question-schema-and-data-model-v1.md`, `stage-4-input-audit.md`
    - **도구:** `README.md`, `code.js`, `manifest.json`

- PR 번호는 아직 발급되지 않았으며 아래 번호는 승인된 분할 순서임
- 기존 로컬 커밋의 SHA는 과거 검토 참조임. 새 PR의 검토 HEAD와 병합 결과는 실제 게시 후 확인할 예정
- 과거 테스트 수치는 원본 브랜치의 실행 당시 결과임. 원본의 문서 분할과 이번 PR1 구성에서는 제품 테스트를 다시 실행하지 않음
