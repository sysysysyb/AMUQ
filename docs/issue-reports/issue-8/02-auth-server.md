PR #24의 큰 구현 커밋을 사용자가 승인한 17개 작업 단위로 다시 구성 중임. 게시된 PR은 `9c1bddd`를 유지하며, 이 문서의 재구성 결과는 아직 게시하지 않음. 기존 브랜치의 구현과 검토 기록은 보존했으며 해당 기능을 옮길 때 함께 반영할 예정임.

## 재구성 1/17 — 인증 환경 설정과 공통 타입

기존 U02 서버 구현을 나누는 첫 작업임. 과거의 `8-1` 등 하위 작업 ID와 구분하며 원래 ID를 변경하지 않음.

### Codex 구현

- **인증 환경 검사:** 기존 구현의 `authApiConfig`, `googleOidcConfig`, `resendWebhookSecret`을 옮겼음. 인증 토큰과 요청 제한용 비밀키는 32바이트 이상이어야 하며, 키 교체 중 이전 서명키도 검증함.
  - `WEB_ORIGIN`은 경로와 인증 정보가 없는 HTTP 주소여야 함. 운영에서는 HTTPS를 요구함. `API_ORIGIN`은 개발에서만 허용하고 test와 production에서는 거부함.
  - Google 설정은 개발에서 생략할 수 있지만 입력하면 세 값을 모두 요구함. 운영에서는 설정을 필수로 하고 콜백을 `WEB_ORIGIN`의 `/api/auth/google/callback`으로 제한함.
  - Resend Webhook 서명키는 운영에서 필수이며 `whsec_` 형식과 디코딩한 키 길이를 검사함. 실제 Webhook 처리는 후속 작업임.
- **공통 타입과 의존성:** 인증 공급자와 사용자 응답 타입을 추가하고 contracts 패키지도 타입 검사에 포함했음. 기존 고정 버전의 Argon2, JOSE와 Svix 의존성 및 잠금 파일을 옮겼음.
  - 공통 타입은 아직 API와 웹에서 사용하지 않으며, 패키지 외부 공개 경로도 추가하지 않음. 실제 사용 시 중복 타입과 패키지 연결을 함께 검토해야 함.
- **환경 예시:** 새 설정 항목과 DB 비밀번호 안내를 추가했음. 예시 값 29개는 모두 빈 값으로 유지함.
- **검증:** 구현 전 검사 21개 중 기존 10개 통과, 새 11개 실패했음. 새 설정 함수가 없고 예시 항목이 부족해서 실패했으며, 구현을 옮긴 뒤 21개 모두 통과했음.
  - 단위 49개와 별도 임시 PostgreSQL 통합 16개 통과했음. 통합에는 기존 프록시 신뢰, DB와 worker 회귀 검사가 포함됨.
  - 고정 잠금 파일 설치, DB 변경 적용과 구조 검사, 같은 변경 재실행, 전체 타입 검사와 린트, 포맷 및 API/Next 빌드 통과했음.
  - HTTP Playwright 2개 통과했음. 첫 실행은 임시 실행 설정의 API 포트와 기존 테스트의 고정 포트가 달라 1개 실패했음. 포트를 맞추고 임시 DB를 다시 준비해 통과했으며 제품 코드는 변경하지 않음. 두 임시 DB 모두 정리했음.
  - DB 구조, 인증 API 경로와 시작 시 연결은 이번 범위에 포함하지 않음. 실제 Google 로그인과 메일 발송, UI 변경과 시각 검사는 수행하지 않음.
