# AMUQ Strategy

## Purpose

개인 학습자는 정답·오답·북마크·테스트 기록을 일일이 적어둘 곳이 마땅치 않고, 메모 시스템에 직접 정리하면 시간이 오래 걸리며 자료를 놓칠 수 있다. 이 때문에 전체 오답률이나 최근 테스트 점수 같은 전반적인 학습 진행 상황을 바로 확인하기 어렵다.

## Positioning

AMUQ는 학습자가 가진 문서 자료를 비공개 문제은행으로 바꾸고, 문제 생성부터 풀이 기록과 반복 학습까지 하나의 순환 과정으로 연결한다. 원본 자료는 변환과 사용자 검토에 필요한 기간에만 비공개로 임시 보관하고, 운영자가 삭제 상태와 실패를 추적·재처리하며 사용자에게 보관 기준과 처리 상태를 안내하여 불필요한 자료 잔존에 대한 불안을 줄인다.

## Users

**Primary:** 공개된 연습문제가 부족하거나 개인 학습 자료를 반복해서 익혀야 하는 시험 준비생 - 예를 들면 대학생과 자격·면허시험 준비생이 포함될 수 있다. 또한 자신의 자료를 여러 객관식 문제로 바꾸고 반복해서 풀어, 자료 내용을 기억하고 시험에 대비하기 위해 AMUQ를 사용한다.

## Boundaries

- 검토가 끝난 원본 자료를 사용자 편의를 위해 장기 보관하지 않는다.
- Mammo 데모 외의 공용 문제은행 제작·운영은 MVP에 포함하지 않는다.
- PDF 문제 생성과 완전한 학습·재학습 순환 중 하나가 빠진 반쪽 MVP는 출시하지 않는다.

_Resist a change when:_ 핵심 학습 순환을 약화시키거나, 원본 자료의 불필요한 보관을 늘리거나, MVP를 운영자 제작 콘텐츠 중심으로 바꾸는 변경일 때 저항한다.

## Key metrics

- **문제은행 학습 전환율** - 자료로 문제를 생성하고 검토한 사용자 중 24시간 이내 첫 테스트를 완료한 비율. DB와 제품 이벤트로 측정한다.
- **14일 반복 학습률** - 첫 테스트 후 14일 이내 서로 다른 3일에 걸쳐 총 5회 이상 테스트를 완료한 사용자 비율. 한 번에 몰아서 푼 경우와 지속적인 학습을 구분한다.
- **재학습 순환 완료율** - 오답이나 북마크가 생긴 사용자 중 14일 이내 오답·북마크 릴레이를 합계 2회 이상 완료한 비율. DB의 학습 세션으로 측정한다.
- **재도전 정답 전환율** - 처음에 틀리거나 답하지 못한 문제 중 이후 재학습에서 정답으로 전환된 문제의 비율. DB의 문제별 학습 시도로 측정한다.
- **원본 자료 삭제 준수율** - 생성 결과 검토가 끝난 작업 중 정해진 시간 안에 원본과 임시 산출물이 삭제된 비율. 정리 작업 상태와 운영 로그로 측정하며 목표는 100%다.

## Tracks

### 신뢰할 수 있는 문제은행 생성

문서 자료를 정확한 문제 초안으로 변환하고, 사용자가 검토·확정할 수 있게 한다.

_Why it serves the approach:_ 개인 자료를 실제로 학습할 수 있는 신뢰할 만한 문제은행으로 바꾸는 출발점이다.

### 끊김 없는 학습·재학습 순환

문제 생성부터 테스트, 오답·북마크 재학습, 진행 상황 확인까지 하나의 흐름으로 연결한다.

_Why it serves the approach:_ 별도의 기록·정리 작업 없이 학습 이력과 개선 상태를 바로 확인할 수 있게 한다.

### 비공개 자료 생애주기와 신뢰

자료를 변환과 검토에 필요한 기간만 비공개로 보관하고, 운영자가 삭제 상태와 실패를 추적·재처리할 수 있게 한다. 사용자에게는 보관 기준과 처리 상태를 명확히 안내한다.

_Why it serves the approach:_ 개인 자료를 맡길 때 생기는 보관·잔존 우려를 줄여 문제은행 생성과 학습 순환을 안심하고 사용할 수 있게 한다.
