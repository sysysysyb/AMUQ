# AMUQ Pretendard Refresh

Figma Desktop에서 로컬 Pretendard를 사용해 AMUQ 파일의 텍스트 스타일을 다시 적용하는 일회성 개발 플러그인입니다.

1. Windows에 Pretendard가 설치되어 있는지 확인합니다.
2. Figma Desktop에서 AMUQ 디자인 파일을 엽니다.
3. `Plugins > Development > Import plugin from manifest...`를 선택합니다.
4. 이 폴더의 `manifest.json`을 선택합니다.
5. `Plugins > Development > AMUQ Pretendard Refresh`를 실행합니다.

컴포넌트 원본과 화면에 배치된 인스턴스 내부 텍스트를 모두 갱신합니다. 글꼴을 먼저 적용한 뒤 기존 텍스트 스타일에 다시 연결하므로, 텍스트를 따로 선택할 필요가 없습니다.
